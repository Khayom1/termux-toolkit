## English

**Termux Toolkit** is a collection of useful command-line tools designed specifically for Termux on Android.

### Features

- Fast system information
- Network diagnostics
- Git status and helpers
- One-command installer
- Clean and modular structure
- Works fully offline after install

### Quick Install

```bash
pkg update -y && pkg install git -y
git clone https://github.com/Khayom1/termux-toolkit.git
cd termux-toolkit
bash install.sh
```

After installation, tools will be available globally.

### Available Tools

| Command     | Description                      |
|-------------|----------------------------------|
| `sysinfo`   | Beautiful system information     |
| `netcheck`  | Network and connectivity check   |
| `gitstat`   | Quick git status for repositories|
| `tk-update` | Update the toolkit               |
